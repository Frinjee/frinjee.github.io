# HTML / CSS / JavaScript standards

## HTML Standards

*   **Reference:** https://html.spec.whatwg.org/
*   **Mobile Compatibility:** All HTML implemented in the output must be 1:1 for a mobile-friendly experience.

*   **Mobile Compatibility:** All JavaScript implemented in the output must be 1:1 for a mobile-friendly experience.
*   **Unconventional Methods:** Any JavaScript tricks or unconventional methods referenced from the above sources must be logically sound and well-justified for implementation.

## Output Format

The output should consist of the generated HTML, CSS, and JavaScript code. Clearly delineate each section.

## Notes

*   Prioritize clean, maintainable, and semantic code across all languages.
*   Ensure that the generated code is performant and accessible.
*   The "1:1 for a mobile friendly experience" implies that the generated code should inherently support responsive design and perform optimally on mobile devices without requiring significant post-generation adjustments. This means considering viewport meta tags, relative units, media queries, and mobile-first design principles.
